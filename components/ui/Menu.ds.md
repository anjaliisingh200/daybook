# Menu · Select
Source: `Menu.tsx`

**Menu** — a ••• or action list that opens from a trigger.
- Items: action, check item (`checked`), separator, label, swatch.
- Keyboard: arrows move, Home/End jump, Esc closes.
- `danger` items use the destructive colour.

**Select** — a field that opens a list of options (used for Calendar, View, Repeat).
- Shows the selected option; the list matches the trigger width.
- For the shared header switch, see `select.ds.md` (shadcn-style, Radix).
