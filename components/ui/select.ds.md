# Select (shadcn-style, Radix)
Source: `select.tsx`

**Use:** the Day / Week / Month switch in the shared date header.

- `SelectTrigger` — 32px field with a chevron.
- `SelectContent` — the popover list, above other layers.
- `SelectItem` — a row with a check on the selected item.

Styled with Daybook tokens, so the accent and the primary colour follow the theme.
